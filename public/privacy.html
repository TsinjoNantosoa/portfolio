Portfolio Assistant Privacy

Last updated: September 8, 2026

Tsinjo AI is a public, read-only assistant that answers questions about Sandaniaina Tsinjo Nantosoa’s professional portfolio.

Data processed

The service processes the messages you submit, an anonymous short-lived session identifier, basic request metadata such as IP address for abuse prevention, and technical error information. Please do not submit confidential, sensitive, or personal information.

Purpose and providers

Messages are used to retrieve relevant public portfolio passages and generate an answer. The backend uses Qdrant for vector retrieval and OpenAI for embeddings and response generation. Those providers process data under their respective terms and privacy policies.

Browser storage

The widget stores its short-lived access token and up to 20 recent messages in sessionStorage. This data is scoped to the current browser tab and is cleared when the tab session ends. The widget does not use localStorage.

Server retention

The application does not create user accounts or a server-side conversation history. OpenAI generation requests are sent with response storage disabled. Operational logs use request IDs and shortened hashes for sessions and network rate-limit keys. They record message length, result status, latency, retrieval count, model name, and error type; they do not intentionally contain message text, access tokens, API keys, IP addresses, or retrieved content. Hosting providers may retain infrastructure logs under their own policies.

Your choices

Using the assistant is optional. You can stop a response, close the widget, clear the current tab session by closing the tab, or contact the portfolio owner about a privacy request.
